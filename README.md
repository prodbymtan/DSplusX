# DSplusX
The average wait time for a new patient doctor appointment in the U.S. is 31 days, driven by systemic workflow bottlenecks, provider shortages, and administrative burdens. 
Relay is a web app that carries a patient’s health information and access to care from one step to the next.

We built this around the premise of solving problems H1 (wearable data → better care) & H2 (keeping residents connected to coverage)
Relay turns the data a wearable already collects into a clean, plain-language snapshot a doctor or ER team can read in under a minute, shown on the patient's own phone.
